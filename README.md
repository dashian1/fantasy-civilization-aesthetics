# fantasy-civilization-aesthetics · 幻想文明美学导演

把一种可感知的**材料**、一组有辨识度的**形态**和一个**文明意象**，发展成可以持续产出不同画面的视觉系统。

目标是：每张图单独有吸引力，多张又能被认出属于同一个世界。

纯 Markdown，无依赖，可供不同用户和智能体独立使用。

## 核心链路

```text
输入理解 → 参考证据 → 材料与形态语法 → 光色及媒介
→ 文明资产 → 景别与题材编排 → 逐条提示词与参数 → 质检修复 → 复用交接
```

## 六条不变量

| # | 不变量 |
| --- | --- |
| 1 | **辨识来自材料和形态共同作用** — 琥珀的内部透光 + 黄铜框架 + 昆虫翼脉共同作用，不是把普通城堡染黄 |
| 2 | **形态跨对象迁移** — 一种母题应能用于建筑、人物、器物、生物、交通，但各类别有自己的功能与比例 |
| 3 | **光线让材料成立** — 区分透射、反射、漫反射和暗部，不让所有东西都发光或共用同一种塑料表面 |
| 4 | **图组有远近变化** — 巨构、角色肖像、室内、机械生物、细节均可作主画面；巨物是能力，不是每张必现的模板 |
| 5 | **丰富但有主次** — 允许繁复装饰、机械密度、祭司、女王、王座、对称和杂志感，用明暗与景深防止杂乱，而非强制极简 |
| 6 | **审美统一比故事完整重要** — 图组可以是世界设定集，不必是连续剧情 |

## 默认值

| 项 | 默认 |
| --- | --- |
| 数量 | 8 张同一世界的美学组图 |
| 画幅 | 16:9（横向电影画面）；明确竖屏则 9:16 |
| 媒介 | 有实体体积、精细材质、摄影式布光的幻想电影概念艺术 |
| 语言 | 中文短标题 + 完整英文提示词 + MJ 参数 |
| 画面文字 | 无文字、无 Logo |

> 不强制东方、独行者、披风、巨环、雷暴、神像、透明材料或高饱和 —— 选择应来自本次主题。

## 八图编排：同一世界的不同观看距离

| 序号 | 类别 | 画面任务 |
| --- | --- | --- |
| 01 | 标志建筑/地景 | 一眼建立风格材质与轮廓 |
| 02 | 城市/生活空间 | 展示结构重复、通行与层次 |
| 03 | 核心角色 | 面部、冠饰、服装展示文明气质 |
| 04 | 生物/交通/器械 | 让形态逻辑跨对象成立 |
| 05 | 功能建筑/装置 | 时间、能源、观测等具体功能 |
| 06 | 室内公共空间 | 从外部进入内部，改变光线 |
| 07 | 遗迹/工坊/细节 | 展示年代、工艺或物质内部 |
| 08 | 第二角色/高潮画面 | 新身份、新姿态或最强视觉 |

十图可增补一张工艺细节和一张生活/异象；三图则选三个最能展示语法差异的类别。

## 提示词按对象编译

不同对象走不同句序 —— 不用一个母句统治所有镜头：

```text
环境：主建筑/城市 → 材料与结构 → 地貌及人类尺度 → 机位层次 → 光学行为 → 色谱与媒介
角色：身份与景别 → 面部/姿态 → 服装与冠饰结构 → 皮肤/织物/硬材对比 → 环境提示 → 光与景深 → 媒介
生物：可辨认身体结构 → 材料分区 → 关节/运动瞬间 → 环境与尺度 → 光线与表面
细节：一个工艺或物件 → 表面/断面/内部 → 周围接触物 → 近距光线 → 媒介
```

正文默认 **60—110 英文词**，每条独立可复制，不写「同上」。

**MJ 参数起点**：新系列可先统一 `--stylize 230 --chaos 6`；更华丽角色试 250/6，优先结构试 200/4。这是创作起点，不是官方推荐。

## 安装

把整个目录放进宿主技能目录（保持相对引用，不要只拷 `SKILL.md`）：

```
~/.workbuddy/skills/fantasy-civilization-aesthetics/
```

## 用法

- `用这个技能做琥珀昆虫文明，8 张，建筑和人物都要，16:9。`
- `参考这张图的材质和光，不复制人物，扩成城市、角色、生物和室内。`
- `换一个新风格，保留华丽材质和电影体积，别整套都是巨环。`
- `只做玻璃宗教的人物近景，3 条，统一 9:16。`
- `保持当前主题，补 2 张内部空间和 2 张服装细节。`

## 与「巨物向」版本的分工

- **本技能** = 通用版：建筑 / 城市 / 角色肖像 / 生物机械 / 室内 / 遗迹全谱，8 张 16:9 起。
- [`monumental-civilization-aesthetics`](https://github.com/dashian1/monumental-civilization-aesthetics) = 巨物向：小人物 × 巨物强尺度差为硬骨架，10 张 4:5 起，带个人风格台账与禁区。

要「小人物面对巨物、强尺度差」走后者；要广义文明美学、含角色近景与室内，走本技能。
