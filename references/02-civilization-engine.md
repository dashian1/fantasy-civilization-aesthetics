# 02｜文明美学生成引擎

## 先写一句看得见的公式

公式：主材料行为＋辅材料对比＋形态来源＋文明意象＋光学表现。
例：半透明琥珀封存有机纹理，旧黄铜构成关节与框架，昆虫翼脉和蜂巢转成建筑与冠饰，沙漠阳光穿透树脂。

“某某神国很史诗很高级”没有设计信息。先有实体关系再命名。世界运行机制可补一句，但不要用大量能源设定取代画面设计。

## 设计卡

| 字段 | 要回答的内容 |
| --- | --- |
| 主题与情绪 | 观众首先看到什么、感觉什么 |
| 主材料 | 表面、内部、薄边、受光、磨损 |
| 辅材料 | 支撑/包边/连接；与主材的光学对照 |
| 对照材料 | 布、皮肤、石、沙等，用来避免全画面同质 |
| 形态来源 | 昆虫、花粉、枝根、矿物、纺织、天文器等，选1—2个 |
| 形态操作 | 放大、层叠、镂空、折叠、嵌入、分叉、环抱 |
| 工艺 | 镶嵌、铸造、接缝、裂纹、修补，与材质匹配 |
| 空间与文化意象 | 神殿、城市、工坊、祭司、商队等按主题选择 |
| 光与色 | 主光源、最亮区域、主色/辅色/对照色 |
| 媒介 | 按参考锁定写实渲染、风格化三维或绘画表现 |
| 排除项 | 本项目3—5个真实跑偏风险，不设通用审美禁令 |
| 英文锚点 | 4—7个高信息量短语，每条根据对象适量重复 |

## 跨对象映射

| 母题 | 建筑 | 人物 | 生物/交通 | 道具 |
| --- | --- | --- | --- | --- |
| 昆虫翼脉 | 屋顶肋架与膜 | 冠饰与肩甲 | 机械翼、展开甲壳 | 扇形仪器、薄膜灯 |
| 蜂巢单元 | 居住舱与窗 | 铠甲分格、饰片 | 储物舱、腹部分节 | 舱匣、封存容器 |
| 瓷釉与骨形 | 壳拱、白塔 | 陶瓷护片、青白衣料 | 分节瓷构实体 | 星仪、瓷柄器具 |
| 玻璃折射 | 透明拱、叠层大厅 | 透明冠、棱镜配饰 | 折光实体 | 透镜与容器 |
| 黑曜与盐 | 黑体量白地表 | 哑黑服饰、浅色边缘 | 黑石遗物或舟 | 镜石与结晶 |

不是每件资产都覆盖全部材料。皮肤与布料保持自身质感，角色才不会变成一团琥珀或纯金雕像。相似结构不意味着相同形状复制到所有物体。

## 光学设计

- 半透明树脂：逆光/侧逆光显厚薄、夹杂物与内层；深黄铜框架给边界。
- 玻璃：边缘高光、背景折射、焦散与局部遮挡；用不透明参照物避免“透明到看不见”。
- 瓷：柔亮釉面、薄边透光或细裂釉；不能全做无厚度玻璃。
- 黑曜：硬质黑轮廓、局部镜面高光，周围盐地反光提供轮廓。
- 湿骨与壳：粗糙干面、湿润暗面、盐迹等分区，不能全部磨成塑料。

这些是视觉设计方向，奇幻材料可偏离现实，但应内部一致。

## 细节密度

三层组织：大轮廓→中层构件→局部纹理。允许高密度机械和装饰；把最复杂区集中在冠饰、节点、边框或局部焦点，保留面部、天空、地表等休息区。简化目标是层级，不是删掉所有装饰。

## 新风格开发

内部尝试2—3个组合，检查能否产出建筑、人物和另一类对象，不成立就换。选择不只依赖陌生名称的组合；具体说明材料、形态或空间改变了什么。现实文化参考涉及真实事实时查可靠资料；幻想宗教、异星议会等标明为创作设定，不编造历史。
