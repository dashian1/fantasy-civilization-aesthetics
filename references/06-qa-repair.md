# 06｜按画面类型质检与修复

## 三类结论分开

文本预检：指令自洽且覆盖任务。
视觉检验：已见到图像，检查模型实际执行。
表现评估：有真实且可比数据，检查观众行为。

三个层级不能互相代替。不以“通过文本检查”声称出图好看；不以好看声称收藏/流量会好；不因一期数据一般断言某材料失败。

## 硬约束

数量、比例、语言、模型、排除项正确；每条独立完整；材料、景别、光线不互相冲突；参数与条目对应；无私有历史假设；无编造参考编号、数据和模型兼容性。

## 图组编辑检查

| 项 | 判断 |
| --- | --- |
| 材质 | 主材有可见光学证据，对照材保持差异 |
| 形态 | 母题真正塑造建筑/服装/生物，而非贴纸 |
| 主次 | 高密度仍可识别主对象，细节有位置 |
| 媒介 | 全组体积、皮肤、表面与光照表现一致 |
| 多样性 | 混合图组有景别和对象变化；单类型请求不强求类别混合 |
| 文明统一 | 工艺、形态和色谱能跨对象认出 |
| 对象特定质量 | 角色看脸与冠饰、巨构看尺度与空间、细节看材料与工艺 |

不对角色肖像使用“小人不够小”扣分；不把仪式姿态、对称或杂志美术自动判为失败。

## 反馈修复表

| 反馈 | 先检查 | 修复 |
| --- | --- | --- |
| 太像最近那套小人圆环 | 题材和景别是否单一 | 换成角色近景、生活城市、内部空间或生物；保留材质规则 |
| 太空、没东西看 | 是否误用极简 | 增加中层构件、交通/使用痕迹、材料内部细节，保留主次 |
| 细节多但乱 | 纹理是否均匀铺满 | 细节集中节点，脸/天空/地表留休息区，景深分离 |
| 太黑 | 暗材和照明是否混同 | 提升环境补光与边缘可读性，保持暗材，不全加霓虹 |
| 没有琥珀/玻璃感 | 是否只有颜色没有光学行为 | 加透射、厚薄、夹杂物、折射边缘和不透明框架 |
| 像塑料 | 所有材质是否同样光滑 | 区分皮肤、织物、旧金属、树脂粗糙度与高光 |
| 不够宏大 | 熟悉尺度是否缺失 | 增加桥、群体、商队、维护道、空气透视 |
| 人物没存在感 | 本来是否该是近景 | 调整景别，不继续缩小人物；给清晰面部/姿态/冠饰 |
| 像普通蒸汽朋克 | 昆虫形态是否只剩齿轮 | 将翼脉、蜂巢、甲壳用作结构，再保留材料光学 |
| 不够统一 | 母题只在一张出现 | 建筑/角色/物件共享工艺和色谱，不直接复制造型 |
| 没有电影体积 | 被统一成平面绘画 | 加接触阴影、材质分层、机位与景深；是否写实按用户意图 |
| 数据一般 | 缺少可比曝光/点击/收藏 | 记录事实，不擅自归因；提出可检验对照而非包爆方案 |

## 实图检验

先看整体轮廓和情绪，再看缩略图识别，再放大材料、脸部、手部、接缝与无意文字，最后并排检查图组一致性。查看原图区域，排除提示词卡的标题对视觉判断的干扰。

保留/局部修复/替换三类处理，给具体原因。每轮先修最影响目标的一项，不全盘重写已经成立的风格。纯文本通常两轮预检足够；付费生成次数由用户授权与预算决定，技能不授权无限试图。
